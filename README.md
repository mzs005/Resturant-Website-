Restaurant Website
This project is a responsive restaurant website built using HTML and CSS. It features a modern design with the following sections:

Navigation Bar: A responsive navigation bar with a hamburger menu for mobile devices.
Showcase: A visually appealing showcase area with a call-to-action button.
About Us: Information about the restaurant, including a brief history and mission statement.
Types of Food: A section showcasing different categories of food with images and links to learn more.
Food Menu: A detailed menu section displaying various food items with descriptions and prices.
Testimonials: Customer testimonials with star ratings and customer photos.
Contact: A contact form for users to get in touch with the restaurant.
Footer: A footer with copyright information.
